# Privacy Keyboard (v0.1, ранний прототип)

Android IME на Kotlin без зависимостей и без единого разрешения в манифесте (нет INTERNET).

## Сборка
1. Откройте папку в Android Studio (Koala+), дождитесь синхронизации Gradle.
2. Build → Build APK(s) или `gradle wrapper && ./gradlew assembleDebug`.
3. APK: `app/build/outputs/apk/debug/`. Установите, откройте приложение,
   нажмите «Включить клавиатуру», затем «Выбрать клавиатуру».

## Статус
Реализовано: IME-сервис; en/ru/ko/uz(лат)/uz(кир); Hangul-композиция (ㅎ+ㅏ+ㄴ=한, двойные
гласные/конечные, перенос конечной в следующий слог, backspace по джамо); uz: `ʻ`, долгое нажатие на o/g → `oʻ`/`gʻ`;
переключение кнопкой и свайпом по пробелу; shift; авто-заглавная; двойной пробел→точка; повтор удаления;
5 стеклянных тем и настройки (прозрачность, матовость, блики, радиус, зазор, высота, анимации); страница проверки безопасности.

НЕ реализовано (честно): предиктивный ввод, автокоррекция, словари, эмодзи, буфер обмена, смена порядка языков,
настройки по раскладкам, языковые пакеты, цифровой/номерной режимы полей, инструментальные тесты, подпись релиза.
Настоящий blur фона приложения из окна IME недоступен: «стекло» — имитация (градиенты, блик, кайма).

Код не компилировался в среде разработки (нет Android SDK/сети) и не проходил аудит — проверьте сборкой.

## Сборка APK без Android Studio (GitHub Actions)
1. Создайте репозиторий на github.com и загрузите в него ВСЕ файлы из этого архива (включая папку .github).
2. Вкладка Actions → Build APK → дождитесь зелёной галочки (3–6 минут).
3. Откройте запуск → Artifacts → скачайте PrivacyKeyboard-debug-apk → распакуйте → установите .apk.
Debug-APK подписан отладочным ключом, для личной установки этого достаточно.
